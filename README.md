# 🌍 Polyglot Rush

Jogo de navegador no estilo speedrun de tradução multilíngue.

**Jogue agora:** https://projetohiagodriver-droid.github.io/polyglot-rush/

## Como jogar

1. Escolha o modo (Fácil, Normal, Difícil).
2. Selecione os idiomas que quer treinar.
3. Traduza as frases para português o mais rápido possível.
4. Acertos geram pontos e sequências aumentam o multiplicador.
5. Erros ou pulos custam tempo.

## Idiomas disponíveis

- Inglês
- Espanhol
- Francês
- Alemão
- Italiano
- Japonês
- Coreano
- Chinês
